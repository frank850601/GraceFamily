# 愛瑰蘭｜互動 3D 空間

網站：https://frank850601.github.io/GraceFamily/

以提供的 FBX 製作網頁互動模型，保留 100 個建築與家具網格，並加入現場照片參考材質。

## 操作

左鍵旋轉、右鍵平移、滾輪縮放；手機單指旋轉、雙指縮放與平移。
支援總覽、俯視、正面及室內視角，水平剖切、線框、家具切換、點選物件與聚焦、PNG 截圖及 GLB 下載。

## 技術

純靜態 HTML / CSS / JavaScript，Three.js 0.180.0，本地依賴無外部 CDN。以 GitHub Pages 從 main 分支根目錄發佈。
本機預覽可執行任何靜態 HTTP 伺服器，例如 `python -m http.server 8091`。

## 來源與限制

來源為 1130613-愛瑰蘭.fbx。移除兩個遠離建築的樓層標高註記；保留建築幾何。
地坪使用專案 SK-7038 木紋貼圖；其餘材質依現場照片與物件名稱近似重建，非實景掃描。
設計模型可能與現場完工家具不同。物件尺寸為幾何外框，未經現場丈量校正。
